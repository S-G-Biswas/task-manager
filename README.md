# Task Manager API

A RESTful API for managing tasks, built with Node.js and Express. It supports full CRUD operations with input validation and error handling.

## Requirements

- Node.js 18 or later
- npm

## Setup

```bash
npm install
node app.js
```

The server runs at `http://localhost:3000`.

Tasks are loaded from `task.json` into memory when the server starts. Changes are not saved back to the file, so restarting the server resets the data.

## API Endpoints

| Method | Endpoint     | Description      | Success |
| ------ | ------------ | ---------------- | ------- |
| GET    | `/tasks`     | Get all tasks    | 200     |
| GET    | `/tasks/:id` | Get a task by id | 200     |
| POST   | `/tasks`     | Create a task    | 201     |
| PUT    | `/tasks/:id` | Update a task    | 200     |
| DELETE | `/tasks/:id` | Delete a task    | 200     |

### Task object

```json
{
  "id": 1,
  "title": "Set up environment",
  "description": "Install Node.js, npm, and git",
  "completed": true
}
```

`id` is generated by the server. `POST` and `PUT` require all three other fields.

### Examples

```bash
# Get all tasks
curl http://localhost:3000/tasks

# Get one task
curl http://localhost:3000/tasks/1

# Create a task
curl -X POST http://localhost:3000/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "Write README", "description": "Document the API", "completed": false}'

# Update a task
curl -X PUT http://localhost:3000/tasks/1 \
  -H "Content-Type: application/json" \
  -d '{"title": "Set up environment", "description": "Install Node.js and git", "completed": true}'

# Delete a task
curl -X DELETE http://localhost:3000/tasks/1
```

## Validation

| Field         | Rule                                                |
| ------------- | --------------------------------------------------- |
| `title`       | Required, non-empty string                          |
| `description` | Required, non-empty string                          |
| `completed`   | Required, boolean (`true` or `false`, not `"true"`) |

## Error Responses

| Status | When                             |
| ------ | -------------------------------- |
| 400    | Request body fails validation    |
| 404    | No task exists with the given id |

A validation error lists every problem found:

```json
{
  "error": "Validation failed",
  "details": [
    "description is required and must be a non-empty string",
    "completed is required and must be true or false"
  ]
}
```

A missing task returns:

```json
{ "error": "Task not found" }
```

## Running Tests

```bash
npm test
```

Stop the dev server first: the tests load `app.js`, which also listens on port 3000.
